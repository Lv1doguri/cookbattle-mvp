# 자취 요리왕 기능 정리

- **대주제**: 기숙사/자취생 문제 해결
- **소주제**: 자취 요리왕
- **해결할 문제**: 자취생들이 귀찮아서 요리를 잘 안 해먹는다 → 어떻게 동기부여를 줄까?

## 1. 레벨 시스템

**의견**: 모든 사용자가 1레벨로 시작 → 대결로 점수를 얻어서 레벨업 (당근마켓 매너온도처럼 다 같이 같은 지점에서 출발)

**이유**: 타겟층은 요리 안 하는 "초보 자취생"이라서, 처음부터 하/중/상 반을 나누는 것보다 직접 성장하면서 레벨을 올리는 게 동기부여가 더 클 것 같음.

**+ 레벨 비슷한 사람끼리 대결**
다 같이 한 무대에서 대결하면 고수가 계속 1등을 가져가서 초보는 금방 흥미를 잃을 수 있다.
→ 레벨은 모두 1부터 시작하되, 대결은 비슷한 레벨끼리 묶어서 진행
(예: 1~5레벨 "새싹 리그" / 6~10레벨 "자취 셰프 리그")

## 2. 핵심 기능

핵심 = 요리 대결 게임 (다양한 게임을 넣자)

### (1) 따라하기 레시피
- 레시피를 처음부터 끝까지 자세히 알려줌
- 초보자가 천천히 따라 하면서 실력을 키울 수 있음

### (2) 재료 주제 대결
- 매번 특정 재료를 주제로 공개 (예: 이번 주 재료는 계란)
- 그 재료로 만든 요리로 대결
- 우승자는 점수를 더 받고 "나만의 특별 레시피"를 공유할 수 있음

**+ 기능들이 하나로 이어지는 흐름**
대결 참가 → 우승 레시피 공유 → 우승자 레시피가 다시 따라하기 레시피가 돼서 콘텐츠가 계속 쌓임

**+ 추가 대결 주제 아이디어**
- 예산 챌린지: 5,000원 이하로 한 끼
- 도구 제한: 전자레인지만 사용 (기숙사생 맞춤) 등

**+ 우승자 정하는 방법**
사진으로는 맛을 알 수 없어서, 사용자 투표로 정하되 평가 항목을 나누면 좋을 것 같음 (비주얼 / 가성비 / 따라하기 쉬움) → 자기 작품에는 투표 못 하게 막기

## 3. 점수 & 베네핏

- 대결 참가만 해도 → 1점
- 1등 5점 / 2등 4점 / 3등 3점
- N점마다 레벨 1 상승
- N레벨부터 베네핏(기프티콘 등) 지급

**+ 점수 보완**
- 대충 올리고 1점만 받아가는 걸 막기 위해 요리 인증샷은 필수
- 따라하기 레시피 완료 인증도 작은 점수 주기
- 연속 참여 보너스 (예: 3주 연속 참가 시 +2점) → 요리 습관 만들기

## 4. 예상 질문: 기프티콘 주면 손해 아닌가요?

**의견**: 앱 중간중간 광고를 넣어서 수익 만들기

**+ 광고만으로는 부족하다는 반박이 나올 수 있어서 같이 준비하면 좋을 것**
- 브랜드 스폰서 대결: "이번 주 재료: ○○ 참치캔" → 상품은 브랜드가 제공
- 기프티콘은 추첨으로 (예: 10레벨 이상 중 매달 5명 추첨 → 비용 한도 정해짐)
